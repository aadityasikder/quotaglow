# QuotaGlow roadmap

QuotaGlow is growing from a Codex usage display into a modular desk companion. The roadmap is directional; unchecked features do not yet have a promised release date.

- [x] Animated touch companion
- [x] Codex usage dashboard
- [x] Room temperature and humidity with DHT11/DHT22
- [ ] Clock and date
- [ ] Internet weather
- [ ] Pomodoro timer
- [ ] Alarm clock
- [ ] Configurable screen rotation
- [ ] Additional sensors and companion reactions

Future screens should use the shared home-mode and touch-menu state machine instead of adding new global gesture toggles. Features that need account data or internet access should remain optional so the local companion continues working offline.
